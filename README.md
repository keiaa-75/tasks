# Google Tasks Overlay

A simple desktop application to display your Google Tasks.

## Features

*   Displays your Google Task lists and tasks.
*   Simple and lightweight.

## Installation

To install the application, you can run the following command:

```bash
pip install .
```

## Usage

To run the application, use the following command:

```bash
google-tasks-overlay
```
